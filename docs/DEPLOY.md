# 部署教學：一步一步把系統架到 Google

照順序做，第一次大約 20 分鐘。每一步做完再做下一步。

**你會用到的檔案**（都在這個 repo 的 `gas/` 資料夾）：

| 檔案 | 貼到哪裡 | 直接開啟（全選複製用） |
|---|---|---|
| `gas/Code.gs` | Apps Script 的 `Code.gs` | https://raw.githubusercontent.com/wenzhotw/astm2026/main/gas/Code.gs |
| `gas/index.html` | Apps Script 新增的 HTML 檔 `index` | https://raw.githubusercontent.com/wenzhotw/astm2026/main/gas/index.html |
| `gas/appsscript.json` | Apps Script 的專案設定檔 | https://raw.githubusercontent.com/wenzhotw/astm2026/main/gas/appsscript.json |

還要準備一份**學生名單 CSV**，欄位是：組別、學號、姓名、Email、手機、是否組長（格式看 `data/roster.example.csv`）。**這份檔案不要放上 GitHub。**

---

## 第 1 步：用政大帳號建一份試算表

1. 用 Chrome 登入**政大的 Google 帳號**（建議用學校帳號，寄信額度比較高，也方便交接）。
2. 打開 https://drive.google.com ，左上角「新增」→「Google 試算表」。
3. 左上角把檔名改成：`ASTM2026 作業系統資料庫`。

> 之後所有資料、上傳的 PDF 都會放在這個帳號的雲端硬碟裡。

## 第 2 步：打開 Apps Script

1. 在試算表上方選單：「擴充功能」→「Apps Script」。會開一個新分頁。
2. 左上角「未命名的專案」點一下，改名成：`ASTM2026 作業系統`。

## 第 3 步：貼上後端程式 Code.gs

1. 左邊檔案列表點 `Code.gs`，把右邊編輯區原本的內容**全部刪掉**。
2. 打開上表 `gas/Code.gs` 的連結，`Ctrl＋A` 全選、`Ctrl＋C` 複製。
3. 回到 Apps Script，`Ctrl＋V` 貼上，按上方的 💾 儲存。

## 第 4 步：新增網頁檔 index

1. 左邊「檔案」旁邊的「＋」→「HTML」。
2. 檔名輸入 `index`（**只打 index，不要打 .html**，系統會自己加），按 Enter。
3. 把新檔案裡預設的內容全部刪掉。
4. 打開上表 `gas/index.html` 的連結，全選、複製，貼進來，儲存。

> 這個檔案很長，貼上後捲到最底，確認最後一行是 `</html>`。

## 第 5 步：設定時區

1. 左邊齒輪「專案設定」。
2. 「時區」選 **(GMT+08:00) 台北**。
3. 勾選「在編輯器中顯示『appsscript.json』資訊清單檔案」。
4. 回到「編輯器」，點 `appsscript.json`，內容全部換成上表 `gas/appsscript.json` 的內容，儲存。

## 第 6 步：初始化並同意權限

1. 回到 `Code.gs`，上方工具列的函式下拉選單選 **`setup`**，按「▶ 執行」。
2. 跳出「需要授權」→「審查權限」→ 選你的政大帳號。
3. 如果看到「**Google 尚未驗證這個應用程式**」：按左下「進階」→「前往『ASTM2026 作業系統』（不安全）」。
   > 這是因為程式是你自己寫的，不是上架的 App，所以 Google 會這樣提醒，屬於正常現象。
4. 看清楚權限清單（試算表、雲端硬碟、寄信、排程），按「允許」。
5. 執行完成後，回到**試算表分頁**，按 F5 重新整理。上方會多出「**ASTM 系統**」選單，下方會有 8 個分頁：學生名單、個人作業、草稿、個人互評、小組互評、小組報告、老師評分、設定。

> 如果學校帳號跳出「管理員已封鎖」，代表政大限制了這類授權，要請電算中心開放，或改用個人 Gmail 帳號部署。

## 第 7 步：匯入學生名單

1. 點下方「**學生名單**」分頁。
2. 上方選單「檔案」→「匯入」→「上傳」→ 選你的名單 CSV。
3. 匯入設定：
   - 匯入位置：**取代目前的工作表**
   - 分隔符號類型：自動偵測
   - 「將文字轉換成數字、日期和公式」：**取消勾選**（避免手機號碼開頭的 0 被吃掉）
4. 按「匯入資料」。確認第一列是標題：組別、學號、姓名、Email、手機、是否組長。

> 就算 0 被吃掉也沒關係，系統會自動補回來。

## 第 8 步：改設定

點「**設定**」分頁，改 B 欄的值：

| 項目 | 要改成什麼 |
|---|---|
| 截止時間 | 例如 `2026-11-22 23:00` |
| 組間互評 | `開` 或 `關` |
| 自動提醒信 | `開` 或 `關` |
| 老師帳號 | 例如 `teacher` |
| 老師密碼 | **一定要改**，改成只有你和老師知道的密碼 |
| 寄件人名稱 | 例如 `ASTM 課程助教` |

「作業說明」和「檔案資料夾ID」不要手動改。

## 第 9 步：檢查

1. 選單「ASTM 系統」→「② 檢查名單」。會告訴你有沒有缺手機、學號重複、哪組組長不是剛好一位、老師密碼還沒改。有問題就回去改到沒問題。
2. 選單「ASTM 系統」→「寄一封測試信給自己」。收到信就代表寄信正常，視窗也會顯示今天剩多少寄信額度。

## 第 10 步：部署成網頁

1. 回 Apps Script 分頁，右上角「**部署**」→「**新增部署作業**」。
2. 左邊齒輪「選取類型」→「**網頁應用程式**」。
3. 填寫：
   - 說明：`第一版`
   - 執行身分：**我（你的政大帳號）**
   - 誰可以存取：**所有人**
4. 按「部署」，複製「網頁應用程式」的網址（`https://script.google.com/macros/s/……/exec`）。

**這個網址就是給學員用的網址。** 可以做成短網址或 QR code。

## 第 11 步：自己先測一次

1. 用手機打開網址，應該看到大倒數首頁。
2. 在「學生名單」最後加一列測試帳號，例如：`1, TEST01, 測試同學, 你的Email, 你的手機, `（是否組長留空）。
3. 用 `TEST01` 和你的手機登入，寫幾個字、繳交。確認：
   - [ ] 有下載到 PDF（如果沒有自動下載也沒關係，確認信裡有 PDF）
   - [ ] 收到確認信，附件是 PDF
   - [ ] 試算表「個人作業」多一列，雲端硬碟「ASTM2026 作業檔案 / 個人作業 / 第1組」有 PDF
4. 用老師帳號密碼登入（首頁最下方「老師登入」），確認看得到剛剛的作業。
5. 測完把測試資料刪掉：「學生名單」的 TEST01 那列、「個人作業」那列、雲端裡那個 PDF。

## 第 12 步：開啟自動提醒信

選單「ASTM 系統」→「開啟自動提醒排程」。之後每天早上 9 點系統會檢查，在截止前三天、前一天寄信給還沒交個人作業的人。

老師也可以在網頁後台「⚙ 系統設定」裡關掉自動提醒信，不用動排程。

---

## 之後要改程式怎麼辦

1. 把新的 `Code.gs` 或 `index.html` 貼上、儲存。
2. 「部署」→「**管理部署作業**」→ 點右邊的鉛筆（編輯）→ 版本選「**新版本**」→「部署」。

**網址不會變**，學員不用換網址。（不要用「新增部署作業」，那會產生新網址。）

## 常見問題

| 狀況 | 原因與解法 |
|---|---|
| 學員說「登入已過期」 | 登入 6 小時後會過期，重新登入就好 |
| 打開網址顯示「找不到指令碼函式 doGet」 | Code.gs 沒貼完整，或沒按儲存，重貼後再部署新版本 |
| 打開網址是空白或 index 找不到 | HTML 檔名不是 `index`，改名後部署新版本 |
| 寄不出信 | 選單「寄一封測試信給自己」看剩餘額度；超過額度要等隔天 |
| 想看誰交了 | 直接看試算表「個人作業」分頁，或用老師帳號登入網頁 |
| 學期結束要交接 | 把試算表和「ASTM2026 作業檔案」資料夾的擁有權轉給下一屆助教或老師 |

## 安全提醒

- 試算表裡有學員手機和 Email，**只分享給老師和助教**，不要設成「知道連結的人都能檢視」。
- 學員的網頁只拿得到自己的資料、同組的繳交狀態，拿不到別人的作業內容和手機號碼。
