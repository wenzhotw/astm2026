# ASTM 2026 課程作業繳交系統

政大 EMBA「高階策略人才管理領袖營（ASTM）」課間作業用的繳交系統。學員直接在網頁上打字寫心得，系統自動排版成統一格式的 A4 PDF；組長上傳小組報告；各組互相評分；老師在後台批改、看互評結果、下載全部作業。

系統有兩種用法，用的是同一份程式：

| 模式 | 檔案 | 資料存在哪 | 用途 |
|---|---|---|---|
| **展示模式** | `index.html` | 瀏覽器記憶體，重新整理就清空 | 試用、展示、開發修改 |
| **正式模式** | `gas/` 資料夾 | 你的 Google 試算表＋雲端硬碟 | 真的給學員用 |

**要正式使用，照 [`docs/DEPLOY.md`](docs/DEPLOY.md) 一步一步部署，大約 20 分鐘。**

> 目前狀態：2026 年 11 月已在 Google Apps Script 正式上線，並實際測過繳交、自動下載 PDF、確認信與老師後台。

## 快速試用

1. 下載這個 repo，直接用瀏覽器打開 `index.html`。也可以開啟 GitHub Pages，網址會是 `https://wenzhotw.github.io/astm2026/`。
2. 首頁和作業說明不用登入就能看。按「去寫心得」等按鈕時才會要求登入。
3. 首頁最下面和登入視窗都有「試用：選一種身分直接體驗」：
   - **組員**：心得已寫好約 1,400 字，可以直接試繳交；七組簡報都已上傳，可以試評分。
   - **組長**：看全組繳交狀況（看不到別人的內容），並送出小組評分與排名。
   - **老師**：上帝視角，看各組互評送出情況、批改、系統設定。

展示用的帳號都是假資料（[`data/roster.example.csv`](data/roster.example.csv)）：

| 身分 | 帳號 | 密碼 |
|---|---|---|
| 第 1 組組長 | `114900001` | `0900000001` |
| 第 1 組組員 | `114900002` | `0900000002` |
| 特邀學員（第 2 組） | `GUEST01` | `0900000012` |
| 老師 | `teacher` | `1234` |

規則：學員帳號是學號，密碼是手機號碼（可以打 `-` 或空白）。

## 功能

### 學員
- **首頁**：大字倒數計時（天、時、分、秒），越接近截止顏色越緊張。下方是待辦清單，照順序做就好。
- **作業說明**：老師講義排好版，有目錄、時間軸、補充資料連結。不用登入就能看。
- **我的作業（個人反思心得）**
  - 直接打字，右邊即時預覽 A4 排版。題目在最上面，水平線下方是「學號　第 N 組　姓名」。
  - 字級 14pt，排不下時自動縮到 13.75pt、13.5pt；兩倍行高，段落之間空半行。
  - 字數上限 1500 字（不含空白），最多兩頁，超過就不能繳交。
  - 每打幾秒自動儲存草稿；從 Word 貼上時自動清掉多餘空白和空行。
  - 繳交前會先顯示完整預覽再確認；繳交後自動下載 PDF（檔名：`第1組_姓名_學號_v2.pdf`），並寄確認信附上 PDF（正式模式）。
  - 截止前三天、前一天，自動寄提醒信給還沒交的人（正式模式，老師可以關閉）。
  - 可以重交，每次會多一個版本（v1、v2…），老師看最新版。
- **幫各組評分**（組間互評，老師可以關閉）：本組簡報上傳後才開放。逐組看簡報、打 0～100 分、寫評語。
- **全組評分彙整**：看組內每個人給各組的分數。
- **互評結果**：已結束的互評（例如第 1 次），每個人都能看綜合排名、名次矩陣和各組評語。進行中的那一次要等老師結束後才公開。
- 互評分好幾次（預設全學期 3 次），頁面會標示「第 N 次互評」。

### 組長（多了這些）
- **上傳小組報告**：只收 PDF，自動改名成「第N組_簡報.pdf」，自動算頁數，超過上限會提醒。
- **送出小組評分**：參考組員分數，拖曳排出第 1～7 名，每組可寫評語，另有整體評語。七組都上傳後才能送出。
- **組員狀況**：誰沒交作業、誰沒評完，一鍵複製 LINE 提醒訊息。

### 老師
- **首頁**：待批改份數、沒交的人、各組上傳與互評狀況。
- **批改個人作業**：連續批改模式，分數和評語固定在畫面下方，按 Enter 就跳下一份。可切換「全部／待批改」，可看舊版本。
- **小組報告評分**：看簡報、看其他組給的分數和評語、打分。
- **互評結果**：分第 1、2、3 次，只呈現小組層級：綜合排名、各組給的名次（顏色標出和綜合排名差幾名）、分數與評語，不列個人評分。
- **下載**：全部作業合併成一份 PDF、每人一份（ZIP，依組別分資料夾）、成績 CSV。
- **⚙ 系統設定**：修改截止時間、開關組間互評、開關自動提醒信、結束這一次互評並開始下一次、設定通知信箱、直接編輯作業說明的每一段。
- **自動通知老師**（正式模式）：七組都上傳簡報時，寄簡報的雲端資料夾連結（資料夾會自動分享給老師）；七組都送出小組互評時，寄綜合排名。每一次互評各寄一次。
- 右上角可以調整全站字的大小。

## 正式模式：名單放在 Google 試算表

照 [`docs/DEPLOY.md`](docs/DEPLOY.md) 部署後，名單直接匯入試算表的「學生名單」分頁，網頁裡不會有任何名單資料，手機號碼只在伺服器端比對。這是給學員使用的建議方式。

## 展示模式換成真實名單（只在自己電腦做，不要上傳）

不想架 Google 時，也可以產生一個放了真實名單的單機網頁，在自己電腦上展示給老師看（資料一樣不會保存）。

真實名單有學員的姓名、Email 和手機，**絕對不要 commit 到這個公開 repo**。`.gitignore` 已經擋掉 `data/roster.csv`、`dist/` 和所有 `.xlsx`。

1. 照 [`data/roster.example.csv`](data/roster.example.csv) 的欄位整理名單，存成 `data/roster.csv`：

   | 欄位 | 說明 |
   |---|---|
   | 組別 | 1～7 的數字 |
   | 學號 | 特邀學員沒有學號時，用 `GUEST01`、`GUEST02`… |
   | 姓名 | |
   | Email | 確認信寄到這裡 |
   | 手機 | 當作登入密碼，09 開頭 10 碼 |
   | 是否組長 | 組長填「是」，每組剛好一位 |

2. 產生正式模式的網頁（會關掉測試用快速登入和測試工具）：

   ```bash
   python3 tools/build.py --roster data/roster.csv --out dist/index.html \
       --no-demo --teacher-id teacher --teacher-password 你自己的密碼
   ```

   工具會先檢查名單：組別、學號重複、手機格式、每組是不是剛好一位組長，有問題會列出來。

3. 手機號碼不會以明文寫進網頁，只存 SHA-256 雜湊。但 10 碼手機的組合不多，有心人還是算得出來，而且姓名和 Email 是明文，所以產生的 `dist/index.html` 不要公開分享。

## 修改系統

- **不用改程式就能改的**：截止時間、組間互評、自動提醒信、作業說明，全部在老師後台的「⚙ 系統設定」，或試算表的「設定」分頁。
- **要改程式的**：請先讀 [`AGENTS.md`](AGENTS.md)。裡面寫了程式結構、每一區在做什麼、常見修改要改哪裡，給助教本人或 AI 助理看都可以。
- 改完跑測試：

  ```bash
  npm install
  npx playwright install chromium
  npm run build   # 改了 index.html 後，同步產生 gas/index.html
  npm test        # 展示模式測試＋模擬 Google 環境的整合測試
  ```
